## 2026-10-22 收尾更新（本地，未发布）

- receipt 手机与横屏卡片的紧凑、均衡、舒展使用对应尺寸的留白；修复样式优先级造成选择无效，保留均衡档原值。
- 备份只收集当前设置、书籍封面及归档内全部截图编辑版本引用的图片；共享图片只存一份。无引用旧图片保留在本机，不再加入 ZIP；引用图片缺失则明确拒绝生成不完整备份。格式仍为 v2，保留 v1 读取。
- 书架可自动读取盘符或 Windows MTP/WPD Kindle 中 EPUB、MOBI、AZW、AZW3 的内嵌 PNG/JPEG 封面。页面可见时每分钟检查缺封面书籍，也提供“从 Kindle 补齐封面”。书名与已知作者须匹配；无作者时要求唯一匹配，不明确的版本由用户手动上传。已有封面优先，不自动覆盖。
- 封面保存在本地媒体目录，支持重载和完整备份；不写回 Kindle，不调用在线书目服务。每批最多读取 8 个电子书，单书不超过 64 MB、封面不超过 5 MB。KFX、加密书籍、没有可读内嵌封面或匹配不明确的书籍继续支持手动上传；本轮未实现系统缩略图缓存读取。
- 新增 fast-xml-parser 解析 EPUB 元数据；Vitest 锁定依赖更新到 4.1.12，修复新报告的测试工具中危漏洞。
- **验收范围调整：用户于 2026-10-22 明确决定跳过“确切传输中拔出”验收。该项记为豁免，不是通过，不再作为 Phase 1 阻塞项。** 原有失败保护、资料保留和普通重连测试继续保留。

本轮自动化：31 个 Node 测试、14 个 UI/存储/尺寸测试通过；lint、类型检查、生产构建、格式检查和依赖审计通过，审计 0 漏洞。覆盖 EPUB 2/3 与 MOBI/AZW/AZW3 匿名样本、盘符扫描、模拟 MTP 隐藏扩展名、重复扫描、版本歧义、已有手动封面、HTTP 同源限制、非法路径、封面备份恢复、孤立媒体排除和历史背景保留。

真实 Edge / 生产构建：receipt 的 phone/landscape × 三档留白共六组计算样式与 PNG 导出通过；phone PNG 为 1080×1920，landscape 为 2160×1494。两种尺寸的中文长文舒展档导出通过，纸张主题紧凑档保持 38px/40px。匿名 EPUB 封面自动补齐、设置重载通过；390×844 的摘录库和卡片工作区均无横向溢出。浏览器测试使用隔离匿名资料，不接触个人书库。

## 交付范围

- 按书名与作者分组浏览摘录；同名不同作者分别展示，支持本地封面上传。
- 新增书页模板，与原有金句、评论、Memo、小票及五种尺寸并存。
- 摘录卡与截图卡共用字体、字号、留白、对齐、图片背景控件；背景与封面保存到本地内容寻址文件，重复图片不产生副本。
- ZIP 备份格式升级为 v2，包含封面与背景；继续读取 v1 备份。恢复保留当前已有书籍封面。
- 修复真实 Windows MTP 截图扩展名隐藏、Size=0 时被扫描器跳过的问题，读取 Shell 的 System.FileExtension 与 System.Size。
- Vite 升级到 8.3.5，修复本轮依赖审计阻断；不额外升级 React 或 TypeScript。
- HTTP 测试使用高位回环端口并处理端口占用，避免 Fetch 拒绝受限端口。
