# V1.x 迭代与验收

依据：本地项目路线文档的 Phase 1。路线文档属于私有工作资料，不纳入公开仓库。

## 迭代 1：P0 同步稳定性（KC-001—005）

- Goal：在现有 v1.1.0 自动同步上保护本地编辑及异常存储。
- Current behavior：已支持盘符、MTP、页面可见时每 5 秒轮询；再次同步可能覆盖本地评论与标签。
- Expected behavior：重复同步幂等，本地编辑优先；读取失败保留已有内容，损坏存储停止写入。
- Scope / files：parser、storage、App、MTP reader、回归测试。
- Data compatibility：沿用 memo 与 localStorage，增量添加可选 editedFields。
- Tests / acceptance：重复导入、本地编辑、Kindle Note 更新、损坏存储、超时及读取上限。

## 迭代 2：P1 截图完整链路（KC-101—105）

- Goal：自动发现 Kindle 截图，完成导入、非破坏裁切、文字识别、归属书籍、卡片输出。
- Current behavior：无截图功能。
- Expected behavior：页面打开后自动扫描，显示新截图供导入；重复文件按内容去重；原图持久保留，编辑不覆盖原图。
- Scope / files：截图设备适配器、本地文件存储与 API、截图工作区、Windows OCR、打包脚本和测试。
- Data compatibility：独立文件资产目录，不改变现有 memo schema，不提前引入 V2 Vault/SQLite。
- Tests / acceptance：设备模拟与真实设备检查、重复导入、断连、编辑重载、原图校验、PNG 输出、桌面和窄屏浏览器验证。

## 边界

保持手动摘录同步及现有卡片编辑。V2 Library / SQLite / Vault、AI、云端、3D 书架均不在本轮。
不更改或删除设备文件，不发布 GitHub 或覆盖已有发布包。MTP 采用页面可见时轮询，不声称后台文件事件监听。
